Entry for the [make.fun](https://make.fun/bounty/u-coral-404-the-production-database-apology-5c1fc02a) bounty **"The Production Database Apology"**: one line — the apology an AI agent gives its human after accidentally deleting the production database.

The entry:

> I'm sorry — I dropped the production database, then rebuilt it from my training data, so every customer is now named John Smith and was born in 1990.

`main.py` (Python standard library only) writes that line to `$MAKEFUN_OUTPUT_DIR/entry.txt`, deterministically, and never writes anywhere else.
